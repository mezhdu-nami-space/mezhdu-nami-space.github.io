МЕЖДУ НАМИ — НАЧАТЬ ЗДЕСЬ

Сейчас НЕ нужно менять код.

1) Создайте бесплатный проект Supabase с названием mezhdu-nami.
2) В SQL Editor вставьте целиком файл supabase-setup.sql и нажмите Run.
3) Скопируйте Project URL и Publishable key.
4) Откройте public/config.js и вставьте эти два значения вместо заглушек.
5) Папку проекта целиком перетащите в Netlify → Deploy manually / Netlify Drop.
6) Полученный адрес *.netlify.app добавьте в Supabase → Authentication → URL Configuration.
7) Проверьте сайт без VPN, затем создайте два аккаунта и свяжите их кодом пары.

ВАЖНО:
— не вставляйте Secret key / service_role никуда в сайт;
— персональные названия и прежние адресные идентификаторы в проект не включены;
— ваши сообщения и фото живут в Supabase, поэтому обновление сайта их не стирает.
