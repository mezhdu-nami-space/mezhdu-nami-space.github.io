# Между нами — версия для простой публикации

Эта копия подготовлена для бесплатной схемы:

- **Supabase Free** — вход двух пользователей, база сообщений/желаний/событий и приватное хранилище фотографий.
- **Netlify Free** — публикация сайта по постоянному адресу `*.netlify.app` без собственного домена.

Проект использует только нейтральное техническое имя `mezhdu-nami`; персональные названия и прежние адресные идентификаторы не включены.

## Что сохранено

- регистрация и вход по email/паролю;
- пространство пары и код приглашения;
- подтверждение второго участника;
- календарь и события;
- фото событий;
- обычный чат и фото в чате;
- удаление своих сообщений у обоих;
- желания, ссылки, цены, фото, бронирование и исполнение;
- приглашения на свидание;
- профили и аватары;
- фон и темы;
- секретный чат с шифрованием на устройстве;
- удаление своих секретных сообщений;
- секретные фотографии;
- импорт события в календарь телефона;
- установка сайта на экран «Домой» как PWA.

## Что изменилось технически

Старая серверная инфраструктура и необязательные внешние интеграции удалены из рабочей схемы. В браузерной версии используется только публичный Supabase Publishable key; секретный/service_role ключ приложению не нужен.

Системные push-уведомления, когда сайт полностью закрыт, в этой бесплатной статической версии отключены. Когда приложение открыто, оно проверяет обновления автоматически.

## Публикация — 4 шага

### 1. Создайте Supabase-проект

Создайте бесплатный проект Supabase с нейтральным названием, например `mezhdu-nami`.

### 2. Создайте базу одной вставкой

В Supabase откройте **SQL Editor**, вставьте целиком файл `supabase-setup.sql` и нажмите **Run**.

### 3. Вставьте две настройки

В Supabase скопируйте:

- Project URL;
- Publishable key вида `sb_publishable_...` (допустим и legacy anon key, но publishable предпочтительнее).

Откройте `public/config.js` и замените только две строки:

```js
supabaseUrl: "ВСТАВЬТЕ_PROJECT_URL",
supabaseAnonKey: "ВСТАВЬТЕ_PUBLISHABLE_KEY",
```

Никогда не вставляйте туда Secret key или service_role.

### 4. Опубликуйте через Netlify

Войдите в Netlify и используйте **Deploy manually / Netlify Drop**. Перетащите папку проекта целиком. В `netlify.toml` уже прописаны команда сборки и папка публикации.

После публикации можно выбрать нейтральное имя проекта, например `mezhdu-nami-space`, если оно свободно. Адрес будет примерно:

`https://mezhdu-nami-space.netlify.app`

После получения адреса добавьте его в Supabase → Authentication → URL Configuration как **Site URL** и разрешённый Redirect URL. Это нужно для подтверждения email и восстановления пароля.

## Как обновлять потом

1. Сохраните текущую рабочую копию проекта.
2. Отдайте её ChatGPT для нужных изменений.
3. В новой версии сохраните свои значения из `public/config.js`.
4. Откройте текущий проект в Netlify → Deploys.
5. Перетащите обновлённую папку проекта в область ручного деплоя.

Адрес сайта останется прежним, а данные в Supabase не удалятся.

## Локальная сборка (необязательно)

Нужен Node.js 22.13+:

```bash
npm ci
npm run build
```

Готовая статическая версия появится в папке `out`.
